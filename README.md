# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

## Objectifs du projet
- Gérer les véhicules, les agences et les réservations
- Permettre la location et le suivi des contrats
- Mettre en pratique la chaîne Java / Spring Boot

## Acteurs
- **Client** : consulte les véhicules, réserve et loue
- **Agent d'agence** : gère les locations et les retours
- **Responsable d'agence** : supervise l'agence, les agents et les statistiques
- **Administrateur** : gère les agences, les utilisateurs et la configuration

## Cas d'utilisation (première liste)
- Consulter le catalogue des véhicules
- Réserver un véhicule
- Enregistrer une location et un retour
- Gérer le parc de véhicules
- Gérer les agences et les utilisateurs
- Consulter les rapports et statistiques

## Environnement
Java 17, Spring Boot, Maven, MySQL, IntelliJ IDEA, Postman, Git
